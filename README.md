# 🧮 Python Calculator

A simple calculator built using Python.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero handling
- Invalid operator handling

## 🛠️ Built With

- Python 3

## 🚀 How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   python Calculator.py
